# AcreetionOS Linux — GNOME Edition

Welcome to AcreetionOS Linux, an open-source project aimed at providing a stable and up-to-date experience built on Arch Linux.

> **This repo builds the GNOME edition ISO.**  
> Looking for another edition? See the [editions list](https://acreetionos.org/wiki.conf).

Download the latest ISO: https://acreetionos.org

## Project Overview

AcreetionOS Linux is a community-driven effort to build a lightweight, versatile Linux distribution. Currently based on Arch Linux LTS, with a future goal of being a parallel distribution with our own base. Our focus is on simplicity, ease of use, stability, and performance on both modern and low-end hardware.

The GNOME edition provides a modern GNOME desktop experience with custom AcreetionOS branding and sensible defaults.

## Features

- Lightweight Arch LTS base system
- GNOME desktop environment with custom wallpaper and theming
- Touchegg gesture enhancements
- Standardized package selection
- User-friendly Calamares installer

## Quick Start

1. Download the latest ISO from [acreetionos.org](https://acreetionos.org)
2. Write it to USB using [AcreetionOS Media Writer](https://github.com/spivanatalie64/AcreetionMediaWriter), [Etcher](https://etcher.balena.io), [Rufus](https://rufus.ie), or [Ventoy](https://ventoy.net) (Ventoy MUST use GRUB MODE 2)
3. Boot from the USB drive and follow the installation instructions
